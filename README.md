# Paradise Nursery - E-Plant Shopping App

Welcome to my plant shopping application! This is a simple web app where you can browse different types of plants and add them to your cart.

## What's This Project About?

I built this as a way to practice React and Redux. It's basically an online plant store where you can:
- Browse plants by category (Air Purifying, Aromatic, Insect Repellent, Medicinal, and Low Maintenance)
- Add plants to your cart
- Manage quantities in your cart
- Calculate totals and checkout

## Tech Stack

- **React** - for the UI
- **Redux** - for state management (managing cart items)
- **Vite** - for fast development and building
- **CSS** - for styling

## Getting Started

1. Clone or download this repo
2. Install dependencies:
   ```bash
   npm install
   npm run dev
## How It Works
1. The app displays plants in different categories
2. Click "Add to Cart" to add a plant
3. Click the cart icon to see your items
4. Adjust quantities or remove items as needed
5. Calculate totals before checkout
